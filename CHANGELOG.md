# Changelog

All notable user-visible changes to the Flatnotes TOS application package.

## 5.5.5-1 — 2026-11-14

### Added
- First release. Flatnotes (`dullage/flatnotes:v5.5.5`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8139 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/flatnotesdocker/`.
